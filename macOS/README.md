# 只因你太美桌宠（120 帧版）

原生 macOS 透明桌面宠物，包含两段经过抠图的真人全身动作。

## 功能

- 舞蹈模式：120 个姿态，15 FPS，8 秒循环。
- 篮球模式：120 个姿态，15 FPS，8 秒循环。
- 左键单击人物：切换舞蹈和篮球模式。
- 按住左键拖动：移动桌宠。
- 右键单击：直接选择模式或退出。
- 不读取鼠标方向，不追随鼠标，也不会根据鼠标位置改变运球方向。
- 桌宠透明窗口尺寸：176 × 230。

## 构建

需要 macOS 13 或更高版本：

```sh
chmod +x build.sh
./build.sh
```

生成文件位于 `Build/`。
